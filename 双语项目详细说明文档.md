## 📋 项目概述 / Project Overview

### 中文
这是一个**PB客户报告订阅系统**，主要用于管理客户信息和他们的报告订阅需求。系统允许客户订阅不同类型的报告，并设置报告的频率、格式和交付方式。

## 🔗 实体关系详解 / Entity Relationships Details

### 📊 数据模型关系图 / Data Model Relationship Diagram

```

    ↓ (一对多关系 / One-to-Many)
```

### 🏦 Client 实体详解 / Client Entity Details

```java
@Entity
@Table(name = "clients")
public class Client {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;           // 主键，自动生成 / Primary key, auto-generated
    
    @NotBlank(message = "Client name cannot be empty")
    @Column(nullable = false)
    private String name;       // 客户名称（必填）/ Client name (required)
    
    @Email(message = "Invalid email format")
    @Column(name = "email")
    private String email;      // 邮箱地址（可选，但格式必须正确）/ Email (optional, but format must be valid)
    
    @OneToMany(mappedBy = "client", cascade = CascadeType.ALL, orphanRemoval = true, fetch = FetchType.LAZY)
    @JsonManagedReference
    private List<ReportSubscription> subscriptions; // 该客户的所有订阅 / All subscriptions for this client
}
```

**注解说明 / Annotation Explanations**:
- `@Entity` - 告诉Spring这是一个数据库实体 / Tells Spring this is a database entity
- `@Table(name = "clients")` - 指定数据库表名 / Specifies database table name
- `@Id` - 标记为主键 / Marks as primary key
- `@GeneratedValue(strategy = GenerationType.IDENTITY)` - 主键自动递增 / Auto-increment primary key
- `@NotBlank` - 验证字段不能为空 / Validates field cannot be empty
- `@Email` - 验证邮箱格式 / Validates email format
- `@OneToMany` - 一对多关系，一个客户可以有多个订阅 / One-to-many relationship, one client can have multiple subscriptions

### 📋 ReportSubscription 实体详解 / ReportSubscription Entity Details

```java
@Entity
@Table(name = "report_subscriptions")
public class ReportSubscription {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;                    // 主键 / Primary key
    
    @ManyToOne(optional = false, fetch = FetchType.LAZY)
    @JoinColumn(name = "client_id", nullable = false)
    @JsonBackReference
    @NotNull(message = "Client cannot be null")
    private Client client;              // 关联的客户（多对一关系）/ Associated client (many-to-one relationship)
    
    @Enumerated(EnumType.STRING)
    @Column(name = "report_type", nullable = false)
    @NotNull(message = "Report type cannot be null")
    private ReportType reportType;      // 报告类型（枚举）/ Report type (enum)
    
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    @NotNull(message = "Frequency cannot be null")
    private Frequency frequency;        // 频率（枚举）/ Frequency (enum)
    
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    @NotNull(message = "Format cannot be null")
    private ReportFormat format;        // 格式（枚举）/ Format (enum)
    
    @Enumerated(EnumType.STRING)
    @Column(name = "delivery_method", nullable = false)
    @NotNull(message = "Delivery method cannot be null")
    private DeliveryMethod deliveryMethod; // 交付方式（枚举）/ Delivery method (enum)
}
```

**注解说明 / Annotation Explanations**:
- `@ManyToOne` - 多对一关系，多个订阅属于一个客户 / Many-to-one relationship, multiple subscriptions belong to one client
- `@JoinColumn(name = "client_id")` - 指定外键列名 / Specifies foreign key column name
- `@Enumerated(EnumType.STRING)` - 枚举以字符串形式存储 / Enums stored as strings
- `@JsonBackReference` - 防止JSON序列化时的循环引用 / Prevents circular references in JSON serialization

**English**:
Use Bean Validation annotations in entity classes to ensure basic data integrity.

```java

private String name;

// 邮箱格式验证 / Email format validation
```

#### 2. 业务逻辑验证 / Business Logic Validation

**中文说明**:
在Service层进行业务规则验证，如防重复订阅。

**English**:
Perform business rule validation in the Service layer, such as preventing duplicate subscriptions.

```java
public ReportSubscription save(ReportSubscription subscription) {
    // 检查是否为新建订阅 / Check if it's a new subscription
    if (subscription.getId() == null) {
        // 查找该客户是否已有相同类型的订阅 / Find if client already has same type subscription
        List<ReportSubscription> existingSubscriptions = subscriptionRepository
                .findByClientIdAndReportType(subscription.getClient().getId(), subscription.getReportType());
        if (!existingSubscriptions.isEmpty()) {
            // 如果已存在，抛出重复订阅异常 / If exists, throw duplicate subscription exception
            throw new DuplicateSubscriptionException(
                subscription.getClient().getId(), 
                subscription.getReportType()
            );
        }
    }
    return subscriptionRepository.save(subscription);
}
```

### 🚨 异常处理机制 / Exception Handling Mechanism

#### 自定义异常类 / Custom Exception Classes

**中文说明**:
系统定义了专门的异常类来处理不同的错误情况。

**English**:
The system defines specific exception classes to handle different error situations.

```java
// 客户未找到异常 / Client not found exception
public class ClientNotFoundException extends RuntimeException {
    public ClientNotFoundException(Long id) {
        super("Client not found with id: " + id);
    }
}

// 重复订阅异常 / Duplicate subscription exception
public class DuplicateSubscriptionException extends RuntimeException {
    public DuplicateSubscriptionException(Long clientId, ReportType reportType) {
        super("Client " + clientId + " already has a subscription for " + reportType);
    }
}
```

#### 全局异常处理器 / Global Exception Handler

**中文说明**:
使用`@ControllerAdvice`创建全局异常处理器，统一处理所有异常。

**English**:
Use `@ControllerAdvice` to create a global exception handler that handles all exceptions uniformly.

```java
@ControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(ClientNotFoundException.class)
    public ResponseEntity<String> handleClientNotFound(ClientNotFoundException e) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(e.getMessage());
    }
    
    @ExceptionHandler(DuplicateSubscriptionException.class)
    public ResponseEntity<String> handleDuplicateSubscription(DuplicateSubscriptionException e) {
        return ResponseEntity.status(HttpStatus.CONFLICT).body(e.getMessage());
    }
}
```

### 🎯 具体例子：创建新客户 / Specific Example: Creating New Client

**中文说明**:
1. **用户操作**: 在网页上填写客户信息并提交
2. **Controller层**: `ClientController.create()` 接收请求
3. **数据验证**: 检查必填字段和邮箱格式
4. **Service层**: `ClientService.save()` 处理业务逻辑
5. **Repository层**: `ClientRepository.save()` 保存到数据库

**English**:
1. **User Action**: Fill in client information on web page and submit
2. **Controller Layer**: `ClientController.create()` receives request
3. **Data Validation**: Check required fields and email format
4. **Service Layer**: `ClientService.save()` handles business logic
5. **Repository Layer**: `ClientRepository.save()` saves to database
6. **Response**: Return success message and redirect to client list page

### 🎯 具体例子：创建报告订阅 / Specific Example: Creating Report Subscription

**中文说明**:
1. **用户操作**: 为客户创建新的报告订阅

4. **Repository层**: 保存订阅到数据库

**English**:
1. **User Action**: Create new report subscription for client

3. **Service Layer**: `ReportSubscriptionService.save()` executes business logic
   - Check if same type subscription already exists (prevent duplicates)
   - If duplicate, throw `DuplicateSubscriptionException`
4. **Repository Layer**: Save subscription to database
5. **Response**: Return success message

#### Q3: "如何防止重复订阅？" / "How to prevent duplicate subscriptions?"
**中文答案**: 在Service层检查客户是否已有相同类型的订阅，如果有则抛出异常
**English Answer**: Check in Service layer if client already has same type subscription, throw exception if exists

#### Q4: "数据库关系是如何设计的？" / "How is the database relationship designed?"
**中文答案**: 客户和订阅是一对多关系，一个客户可以有多个订阅，但每个订阅只属于一个客户
**English Answer**: Client and subscription have one-to-many relationship, one client can have multiple subscriptions, but each subscription belongs to only one client

#### Q5: "如何保证数据完整性？" / "How to ensure data integrity?"
**中文答案**: 使用JPA注解进行约束，业务层验证，异常处理机制
**English Answer**: Use JPA annotations for constraints, business layer validation, exception handling mechanism
